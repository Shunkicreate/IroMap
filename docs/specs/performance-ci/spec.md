# Performance CI Spec

## 要求

- FR-1: 描画関連の限定したコンポーネント群で、不安定な props を静的解析し CI で検出する
- FR-2: production build で画像解析・点選択・矩形選択の派生計算を計測し、中央値の絶対上限を CI で強制する
- FR-3: 計測不足や不正な計測値を成功として扱わず、完了した計測結果を artifact に保存する

## 受け入れ条件

- 既存 lint コマンドで react-perf 違反がエラーになる（FR-1）
- 512x512 / 3840x2160 の各サイズで 2 回ウォームアップ、10 回の実測を行う（FR-2）
- 計測と静的解析の適用範囲・閾値を開発ドキュメントから確認できる（FR-1, FR-2）
- 閾値超過・欠損・非有限値・負値・設定不正の判定に自動テストがある（FR-3）

## 対象外

- DB の N+1 検出、FPS、描画完了までの時間、過去 CI 実行との相対比較
