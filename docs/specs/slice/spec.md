# Feature Spec: Slice表示

## 1. 背景

- 色空間の特定断面を観察することで、色の連続性や変化を平面的に理解できる
- 3D表示だけでは把握しづらい値の推移を補助する

## 2. スコープ

### In Scope

- RGBの任意軸を固定して2D断面を表示する
- 断面の固定値を操作して表示を更新する
- 断面の位置を3D表示と同期する
- RGBキューブとの並置を前提に探索導線を最適化する
- 画像由来のマッピングと選択色マッピングの表示を個別に切り替える

### Out of Scope

- 断面の多重比較
- 断面の保存/エクスポート

## 5. 機能要求

### FR-1: 断面を2Dグリッドで表示できる

#### 受け入れ条件

- 断面は2Dグリッドとして表示される
- 断面の軸選択に応じて色分布が変化する

### FR-2: 断面の固定値を操作できる

#### 受け入れ条件

- 固定値をスライダー等で変更できる
- 操作後に2Dグリッド表示が更新される

### FR-3: 断面位置が3D表示と同期する

#### 受け入れ条件

- 2D断面の位置が3D表示上に反映される
- 断面変更時に3D表示も更新される
- 色空間タブの状態に関わらず、断面固定軸は RGB（R/G/B）として扱われる

### FR-4: 断面UIはキューブ観察と近接して利用できる

#### 受け入れ条件

- 軸/固定値操作と2D断面キャンバスが、RGBキューブの近傍に配置される
- ユーザーはキューブと断面を頻繁に往復しても操作の中断なく確認できる

### FR-5: 断面上の補助マッピング表示を切り替えできる

#### 受け入れ条件

- 画像由来の白マッピングを表示/非表示できる
- 選択色のオレンジマッピングを表示/非表示できる
- 表示切替 UI は折りたたみ内に配置される

### FR-6: ボタン一つで選択色の断面位置へ移動できる（Issue #87）

#### 受け入れ条件

- 軸/固定値操作の近くに「選択色の高さへ移動」ボタンを表示する
- 選択色がない場合はボタンを無効にする
- 現在の色空間と固定軸を維持し、選択色の該当成分を固定値に設定する
- RGB は R/G/B、HSL は H/S/L、Lab は L\*/a/b の全固定軸に対応する
- 固定値は整数に丸め、各軸のスライダー範囲内に収める
- 2D断面、固定値表示、スライダー、3D断面位置を同じ状態で更新する
- 移動しても選択色は変更せず、ホバー色は移動先として使わない
- キーボードとモバイル画面でも操作できる
