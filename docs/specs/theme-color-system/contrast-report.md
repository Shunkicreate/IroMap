# Contrast Report: テーマの色ルール

- tokens.jsonから生成。判定には丸め前のsRGB相対輝度比を使用する。
- 142組を検査し、すべて指定下限を満たした。
- 配色の数値検査。実画面のアクセシビリティ、任意画像上の二重輪郭、視覚承認は別に確認する。
- 装飾線border.subtleは識別境界に使わないため、この必須検査に含めない。
