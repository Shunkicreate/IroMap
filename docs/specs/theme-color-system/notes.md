# Notes: テーマの色ルール

## 確定している方向

- ライトは#FDD9D9よりさらに淡く上品な桜。背景は白に寄せすぎず、彩度を抑える。「操作と選択」の色が好みに合う。
- ダークは夕景写真上部の紺を起点に、青みを保ちながらベースの明度を下げる。
- 両モードのアクセントは目立ちすぎない。桜と抹茶、夕暮れと金星のような色の関係も設計する。
- 別worktreeで設計する。設計に実装が従い、日付別のspec管理はしない。

## 提案する値と関係

- ライト: ベース#F3EFF0、メイン#FCE6E8、添え色の抹茶#E7EDDF。
- ダーク: ベース#161C22、パネル#1B2229、メイン#A8B9CA、添え色の金星#EAE1C4。
- 「操作と選択」の背景は実UIでは明るすぎるという指摘に合わせ、パネル・重なる面・ホバーの面の明度を抑える。
- 淡い主操作は暗い文字と識別できる輪郭で支える。
- 添え色は小さな注記・印。大きな塗りボタンや広い面には使わない。
- 写真・3D・断面の内側は無彩色。分析対象の色をテーマで変えない。

## レビューで確認すること

- ライトの背景に桜を感じるか。主操作は#FDD9D9より淡く上品に見えるか。「操作と選択」の色を保ち、背景の赤みを抑えた結果がイメージに合うか。
- 紺に青が十分に感じられ、夕暮れの深さも保たれているか。
- 抹茶と金星がメインより控えめで、画面の色の関係として自然か。
- 配色見本の視覚レビューはユーザーのLGTMで承認済み。既定テーマ、Liquid Glass、部品寸法はここで決定しない。

## プレビューと検証

- 正本の39意味トークンを両モードで定義し、キー・HEX形式・役割・無彩色の観察面を検査する。
- 142色対を検査し、指定下限を満たした。淡い塗りは輪郭を内外の両側で検証する。
- preview.htmlは配色の確認資料。完成画面や状態遷移のプロトタイプではない。
- 固定のデータ色サンプルを両モードへ同じ値で表示する。提供写真はコピー・公開しない。
- 配色見本の視覚承認は完了。承認済みルールをアプリへ適用する。実画面のユーザー承認はプレビューで別に行う。
- Noto Sans JPと本文・説明文の字間0.04emはユーザー承認済み。色と文字の基礎ルールは設計PRでマージ済み。アプリへの適用をimplementation.mdへ記録する。
- 操作名・数値の字間、サイズ・ウェイト・行間、数値専用書体は未確定。foundation-review.mdの残るUI基礎も検討項目として扱う。

## 実画面レビューによる再検討

- キューブ等の観察面と周囲のUIの相性についてユーザーから差し戻し。配色見本の承認を、実画面の承認とは扱わない。
- 再検討の背景・比較案・採否基準を[color-reassessment.md](color-reassessment.md)へ整理する。採用値はtokens.jsonとdesign.mdへ反映済み。

- A案を実装。作業領域を同じ無彩色で連続させ、カードの多重枠を除き、表示領域は細い線で囲った。描画情報の表示切替と上端の修正を含む仕上がりについてユーザーが明示的に承認。tokens.jsonのstatusをapprovedとする。
