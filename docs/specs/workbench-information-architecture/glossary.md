# IroMap 共通用語集

- 位置づけ: 設計会話と表示文言のための標準語彙。設計草案でありアプリの言語辞書を直接変更するものではない。
- 根拠: 本人の説明・訂正、既存の表示と計算式。
- 関連: [情報の重要度と開示階層](information-architecture.md)、[標準表示文言](ui-copy.md)。
- 目的: 同じ言葉で違う対象を指さない。同じ対象に不要な別名を増やさない。
- 背景: 写真の位置、色空間の位置、選択範囲、選択色が同じ画面で扱われる。
- 状態遷移・操作イベント・保持規則は定義しない。

## 用語の使い方

- 見出しの名称は設計会話の正準名。
- 表示名は画面の入口・ラベルに使う名前。
- 実装名は既存コードとの対応のためだけに記録する。
- 専門語は削除せず、必要な場所では日本語の意味と記号を一緒に示す。
- 写真と画像、選択色と選択範囲、HSL LとLab L\*、HSL彩度とクロマは区別する。
- 未確定の新機能を既存の用語に含めない。
- 軸の表記はRGB: R/G/B、HSL: H/S/L、Lab: L\*/a\*/b\*。
- 単位は角度°、割合%、表示寸法px、処理時間msを使う。
- 表示文言の具体的な文字列はui-copy.mdを正本とする。

## 用語の定義

### T-01 写真

- 定義: 分析対象の写真・画像。静止画像を指す。
- 表示名: 写真。
- 目的: 利用者が調べる対象を一語で呼ぶ。
- 背景: 本人の主用途は写真・画像の色分析。
- 対応する情報要素: P-00、X-02-I。
- 補足: 設計会話では写真。ファイルを選ぶ操作では対応対象に合わせて画像。

### T-02 画像入力

- 定義: 写真をファイルまたはクリップボードから指定する入口。
- 表示名: 画像を選ぶ／画像を貼り付け。
- 目的: 入力方法と対象を区別する。
- 背景: 入力頻度は一枚の作業につき通常一度。
- 対応する情報要素: P-01、P-02。
- 補足: アップロードはサーバー送信が明確な場合だけ使う。

### T-03 作業画面

- 定義: 写真の色を図で観察する主画面。
- 表示名: 表示名を新設しない。
- 目的: 複数の情報領域をまとめて指す。
- 背景: 既存のColorWorkbenchを設計会話で識別する。
- 対応する情報要素: W-00。
- 補足: ワークベンチはコード名の対応語として残す。

### T-04 選択色

- 定義: 利用者が現在の参照対象として選んだ一つの色。
- 表示名: 選択色。
- 目的: 現在の対象を識別する。
- 背景: 元の色を比較の基準色として保持しないという本人の決定。
- 対応する情報要素: W-03、I-04、S-06。
- 補足: 基準色・元の色・候補色の複数枠を含めない。

### T-05 カーソル位置の色

- 定義: ポインター付近で一時的に参照している色。
- 表示名: カーソル位置の色。
- 目的: 選択色と一時参照を区別する。
- 背景: 既存インスペクタにはホバー参照がある。
- 対応する情報要素: I-02、I-03。
- 補足: ホバーは開発用の別名。タッチで常時必要な情報として扱わない。

### T-06 選択点

- 定義: 写真内の対象を示す一つのサンプルの目印。
- 表示名: 文脈内で点。
- 目的: 写真の位置を特定する。
- 背景: 写真の色と色空間の位置を対応づける。
- 対応する情報要素: P-06。
- 補足: 色空間の一点とは同義にしない。

### T-07 選択範囲

- 定義: 写真内で分析の対象として指定する画素の集合。
- 表示名: 選択範囲。
- 目的: 一つの色と複数サンプルの集合を区別する。
- 背景: 既存の点・領域・色近傍による分析対象がある。
- 対応する情報要素: P-07、C-09、S-10。
- 補足: 範囲は矩形だけを意味しない。選択色の履歴でもない。

### T-08 写真の点

- 定義: 写真から採取したサンプルを色空間に配置したもの。
- 表示名: 写真の点。
- 目的: 点の由来を明示する。
- 背景: 白マッピングは3Dの実際の色付き点に一致しない。
- 対応する情報要素: C-08、S-09。
- 補足: マッピング・白マッピングはコード対応語としてのみ残す。

### T-09 選択範囲の点

- 定義: 写真の選択範囲に属するサンプルの配置。
- 表示名: 選択範囲の点。
- 目的: 図の強調対象を明確にする。
- 背景: selectedSamplesとselectedColorは別の情報。
- 対応する情報要素: C-09、S-10。
- 補足: 選択色の目印と呼び分ける。

### T-10 色空間の点

- 定義: 写真とは独立した規則的な色の配置。
- 表示名: 色空間の点。
- 目的: 基準の色配置と写真の分布を区別する。
- 背景: 既存3Dのgrid表示がある。
- 対応する情報要素: C-01、C-07。
- 補足: 写真のサンプリンググリッドと呼び分ける。

### T-11 3Dキューブ

- 定義: 色空間内の位置と分布を立体的に示す既存の図の名前。
- 表示名: 3Dキューブ。
- 目的: 既存の主要表示を一貫して呼ぶ。
- 背景: 既存名を継承し用途説明で補う。
- 対応する情報要素: C-00。
- 補足: HSLのガイド形状が立方体であるという意味ではない。3Dビューは会話上の別名。

### T-12 スライス

- 定義: 色空間の一つの軸を固定した二次元の断面。
- 表示名: スライス。
- 目的: 既存の主要表示と断面の意味を対応づける。
- 背景: 本人は既存名を理解しつつ言葉の明確化を求めている。
- 対応する情報要素: S-00。
- 補足: 断面は意味の説明に使う。名前を二つ並列に増やさない。

### T-13 固定軸

- 定義: スライスで値を一定にしている座標軸。
- 表示名: 固定する軸。
- 目的: 図の向きと値の意味を識別する。
- 背景: どの方向を調べているかの手掛かりが必要。
- 対応する情報要素: S-03。
- 補足: 横軸・縦軸とは別の軸。

### T-14 固定値

- 定義: 固定軸の座標の値。
- 表示名: 固定値。
- 目的: スライダーが表す位置を示す。
- 背景: 色空間によって範囲と単位が違う。
- 対応する情報要素: S-04。
- 補足: 彩度など特定の量に固定した用語ではない。

### T-15 選択色の高さ

- 定義: 選択色の固定軸における値。
- 表示名: 選択色の高さへ移動。
- 目的: 本人が指定した既存ボタンの意味を明確にする。
- 背景: 音声転記の解釈を本人が確認済み。
- 対応する情報要素: S-06。
- 補足: 画面上の縦位置や常に輝度を意味するものではない。

### T-16 横軸・縦軸

- 定義: 断面図またはグラフで横・縦方向に配置した軸。
- 表示名: 横軸／縦軸。
- 目的: 図の方向を日常語で示す。
- 背景: X/Yだけでは初見の意味が分かりにくい。
- 対応する情報要素: S-05、A-12-G、A-14-G、A-16-G。
- 補足: 軸記号と単位を併記する。

### T-17 RGB

- 定義: R・G・Bの値で色を扱う色空間。
- 表示名: RGB。
- 目的: 既存の基本表示の座標を識別する。
- 背景: 既存の初期表示はRGB。
- 対応する情報要素: C-03、S-03。
- 補足: この画面の各成分の範囲は0〜255。HEXやrgb()は表記形式。

### T-18 HSL

- 定義: 色相H・彩度S・明るさLで色を扱う色空間。
- 表示名: HSL。
- 目的: 利用者が意図した色空間の名前を共有する。
- 背景: HTMLという音声転記を本人がHSLと訂正。
- 対応する情報要素: C-03、S-03。
- 補足: 画面上のHは0〜360°、S/Lは0〜100%。

### T-19 Lab

- 定義: L\*・a\*・b\*で色を扱う既存の補助的な色空間。
- 表示名: Lab。
- 目的: 専門的な座標と指標を識別する。
- 背景: 本人は初期値としてのLabを却下、機能削除は指定していない。
- 対応する情報要素: C-03、A-18。
- 補足: 計算上はCIELAB。L\*・a\*・b\*の星を省略しない。

### T-20 色相

- 定義: HSLのHに対応する色の方向の値。
- 表示名: 色相 H。
- 目的: 角度で表す軸の意味を示す。
- 背景: 断面とヒストグラムで使われる。
- 対応する情報要素: S-03、A-14-G。
- 補足: 単位°。無彩色の色相の扱いは既存算出を継承。

### T-21 彩度

- 定義: HSLのSに対応する値。
- 表示名: 彩度 S。
- 目的: HSLの軸・分布を明確にする。
- 背景: Labのクロマとは算出が違う。
- 対応する情報要素: S-03、A-16-G。
- 補足: C\*の指標をHSL彩度と同じものとして説明しない。

### T-22 HSLの明るさ

- 定義: HSLのLに対応する値。
- 表示名: L（明るさ）。
- 目的: Lab L\*と同じ記号の混同を避ける。
- 背景: 複数の色空間を同じ画面で扱う。
- 対応する情報要素: S-03。
- 補足: 範囲0〜100%。Lab明度L\*と別の値。

### T-23 明度

- 定義: 主画面の分析表と明度ヒストグラムで使うLabのL\*。
- 表示名: 明度 L\*。
- 目的: 実際の計算値を正しく示す。
- 背景: 内部名luminanceのヒストグラムはstore.labLから算出される。
- 対応する情報要素: A-M01、A-M02、A-M03、A-12-G。
- 補足: 物理量の輝度と呼び分ける。HSL LやAPIの平均明るさと別の値。

### T-24 クロマ

- 定義: 主画面のC\*=sqrt(a\*²+b\*²)として算出する値。
- 表示名: クロマ（C\*）。
- 目的: HSL彩度と区別し計算に合う名称を使う。
- 背景: CMeanとCP95の説明に必要。
- 対応する情報要素: A-M06、A-M07。
- 補足: 既存グループ名彩度は実装上の別名として記録。標準グループ名はクロマ。

### T-25 無彩色からの距離

- 定義: 主画面の現実装ではC\*として算出する距離。
- 表示名: 無彩色からの距離。
- 目的: 中立という抽象語を具体化する。
- 背景: neutral_distance_meanは現実装でC\*平均と同じ値。
- 対応する情報要素: A-M08、A-M11。
- 補足: 別のΔE計算や平均色との距離として説明しない。

### T-26 ハイライト

- 定義: 主画面の指標ではLab L\*>80のサンプル。
- 表示名: ハイライト。
- 目的: 指標の対象領域を明示する。
- 背景: 白という既存グループ名だけでは対象が曖昧。
- 対応する情報要素: A-M09、A-M10、A-M11。
- 補足: 白という品質評価や白画素だけの分類ではない。標準グループ名はハイライト。

### T-27 95パーセンタイル

- 定義: サンプルの95%がその値以下となる位置の値。
- 表示名: 95パーセンタイル。
- 目的: p95の意味を説明する。
- 背景: 明度とクロマの既存指標に使われる。
- 対応する情報要素: A-M03、A-M07。
- 補足: 上位5%の平均値ではない。丸めと算出方法は既存を継承。

### T-28 ヒストグラム

- 定義: 値の区間ごとにサンプル数を示す棒グラフ。
- 表示名: 明度／色相／彩度ヒストグラム。
- 目的: 図の種類と対象を合わせて識別する。
- 背景: 外部AIへ相談するときにも重要な補助情報。
- 対応する情報要素: A-12、A-14、A-16。
- 補足: フィットグラムの音声転記は本人が訂正に同意済み。

### T-29 区間

- 定義: ヒストグラムの一つの棒が数える値の範囲。
- 表示名: 区間。
- 目的: ビンの意味を共有する。
- 背景: 棒には開始・終了・件数の情報がある。
- 対応する情報要素: A-12-G、A-14-G、A-16-G。
- 補足: コピー内のbinIndexなど既存キーの変更は今回の範囲外。

### T-30 サンプル

- 定義: 写真から分析用に採取された画素のデータ。
- 表示名: サンプル数／点。
- 目的: 画素総数と解析対象数を区別する。
- 背景: サンプリング密度を設定できる。
- 対応する情報要素: P-13、P-16、A-12-G。
- 補足: 図上では点、集計ではサンプル数。解析画像の縮小もあり元画像の全画素と同一と断定しない。

### T-31 サンプリング密度

- 定義: 既存設定が指定するサンプル採取の割合。
- 表示名: サンプリング密度。
- 目的: 細かさと負荷の前提を示す。
- 背景: 既存の設定と初期値40%を継承。
- 対応する情報要素: P-13。
- 補足: 解析対象画像に対する設定。採取位置の格子と混同しない。

### T-32 色面積比

- 定義: 量子化した代表色ごとのサンプル割合。
- 表示名: 色面積比。
- 目的: 全体の色の比重を読む。
- 背景: 上位5色とその他を既存表示する。
- 対応する情報要素: A-10、A-11。
- 補足: 元画像の厳密な領域分割の面積として説明しない。

### T-33 散布図

- 定義: a\*とb\*を座標にしてサンプルを配置する二次元の図。
- 表示名: Lab a\*-b\*散布図。
- 目的: 3Dキューブや断面とは別の補助分析を識別する。
- 背景: 専門的な既存表示を維持する。
- 対応する情報要素: A-18、A-19。
- 補足: 現在の散布図の点は写真のサンプル。

### T-34 分析表

- 定義: 写真全体の数値指標をまとめた表。
- 表示名: 分析表。
- 目的: 既存の補助領域を識別する。
- 背景: 利用頻度が低くても外部評価への用途がある。
- 対応する情報要素: A-01、A-02。
- 補足: インスペクタの色コードの値とは別。

### T-35 色の数値

- 定義: カーソル色と選択色の色コードを扱う補助情報。
- 表示名: 色の数値。
- 目的: 内容から入口を理解できるようにする。
- 背景: 既存インスペクタの内容を継承。
- 対応する情報要素: I-00。
- 補足: インスペクタはコードの対応語として残す。

### T-36 色コード

- 定義: HEX・rgb()・hsl()の色の文字列表現。
- 表示名: HEX／rgb()／hsl()。
- 目的: 貼り付ける対象と形式を示す。
- 背景: 写真のペーストと色のペーストは異なる。
- 対応する情報要素: I-05、I-06、I-07、I-08。
- 補足: 色空間と文字列の書式を同義にしない。

### T-37 表示設定

- 定義: 図や写真の表示量を調節する低頻度の項目。
- 表示名: 表示設定。
- 目的: 設定の入口を統一する。
- 背景: 頻繁な図の観察を設定で圧迫しない。
- 対応する情報要素: P-09、C-05、S-07。
- 補足: 三つの入口は所属領域で識別、内容をすべて共通にする意味ではない。

### T-38 コピーの形式

- 定義: 既存の分析データをクリップボードへ出す書式。
- 表示名: コピーの形式。
- 目的: 操作とファイル保存を混同しない。
- 背景: 既存のMarkdown／CSV／TSVを継承。
- 対応する情報要素: A-04。
- 補足: 内容・対象・出力キーの再設計はスコープ外。

### T-39 全体の色の傾向

- 定義: 既存ルールが出す色相バランスと彩度傾向の短い要約。
- 表示名: 全体の色の傾向。
- 目的: 解釈の入口を示す。
- 背景: ユーザーの現像の目標そのものではない。
- 対応する情報要素: A-07、A-08、A-09。
- 補足: 自動診断・AIの助言・色移動の提案として説明しない。

### T-40 APIの平均明るさ

- 定義: APIでRGB成分の平均を0〜100にした値を画素間で平均したもの。
- 表示名: Average brightness。
- 目的: 同名の異なる算出値を識別する。
- 背景: APIと主画面には別の分析処理がある。
- 対応する情報要素: X-06、R-02。
- 補足: Lab L\*の平均へ無言で置き換えない。

### T-41 重要度

- 定義: 利用者の作業における情報の優先順位。
- 表示名: 画面には表示しない。
- 目的: 設計判断の共通尺度を作る。
- 背景: 参照頻度と操作頻度は別。
- 対応する情報要素: 全要素。
- 補足: P1/P2/P3は削除可否でも状態でもない。

### T-42 開示階層

- 定義: 主情報・入口・要求時の詳細を分ける文書構造。
- 表示名: 画面には表示しない。
- 目的: 情報を一括で露出しないための尺度。
- 背景: H4/H5は詳細のグループと項目。
- 対応する情報要素: 全要素。
- 補足: 実際の表示条件や状態遷移を定義する用語ではない。
