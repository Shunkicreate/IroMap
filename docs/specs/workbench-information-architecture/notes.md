## 3. 既存実装との境界

参照: `.worktree/feature/issue-86-mobile-image-paste/web/src/features/`。別作業ブランチのコード調査であり、最新mainの実機監査ではない。

- 写真の点・領域選択、色空間切り替え、断面軸・値の操作が存在する。
- 参照した断面実装には「選択色の高さへ移動」に相当する明示ボタンがある。
- 同実装ではその操作時に固定軸の値を選択色から取得し、値を丸めて範囲へ収める。設計で正確な一致を扱う際は精度を再確認する。
- 色選択と分析の選択状態は別に存在する。今回決定した単一の確定色と自動追従が実装済みとは扱わない。
- 参照したホバー解決には近傍サンプル探索がある。近傍対応を元の厳密な画素位置として表現しない。

既存挙動の棚卸しと、今回の望ましい挙動との差分は後続タスク。

Q-08の解除タイミング、Q-10の成功時だけ差し替えを反映する方式は、本人の指定を満たすための設計補完。
