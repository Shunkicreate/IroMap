# Design: 3D色空間の目盛り

## 1. 目的

FR-1 / FR-2: 既存Canvas軸ガイドを数値付きの定規として描画する。

## 2. 全体方針

- `rgb-cube-guides.ts`で目盛りの値と描画を管理する。
- 正規化座標−1〜1を既存の`projectSpacePoint`で投影する。RGBは`colorChannelMax`、Labは`labAxisRange`を参照する。
- RGB / Labの定規は点群中心を避けて境界辺に配置する。HSLは底面の成分軸と円柱側面のL軸に配置する。
- 投影した軸に垂直な方向へ短い目盛り線と数値を配置する。
- 縦軸を先に描画し、各軸の端点・中央を中間目盛りより優先する。ラベルの矩形同士と左上の既存ステータス表示との重なりを避ける。
- 数値の背景はCanvasの背景色。`save` / `restore`で文字配置などの描画状態を局所化する。
- `rgb-cube-canvas.tsx`では点群・選択マッピング描画後に軸ガイドを描く。

## 10. トレードオフ

目盛りは常に手前に描くため、奥行きの遮蔽より数値の読みやすさを優先する。狭い画面や軸が短く投影される角度では重なるラベルを間引く。
