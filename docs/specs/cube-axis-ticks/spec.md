# Feature Spec: 3D色空間の目盛り

## 1. 背景

Issue #89: 軸名だけでは3D上の明るさや色成分の値を読み取れない。

## 2. スコープ

- RGB / HSL / Labの既存軸ガイドに目盛りと数値を追加する。
- 色変換、写真分析、スライスの操作仕様は対象外。

## 5. 機能要求

### FR-1: 色空間に対応した目盛りを表示する

#### 受け入れ条件

- RGBはR/G/Bそれぞれ0、64、128、191、255を表示する。
- HSLの縦軸Lは0、25、50、75、100%を表示する。
- HSLの横軸はS·cos(H) / S·sin(H)の成分として−100〜100%を表示する。色相角度や彩度そのものと混同しない。
- LabはL*が0、25、50、75、100、a*/b*が−128、−64、0、64、128を表示する。
- 軸名と最大値を同じラベルに表示する。HSLのLは明度、LabのL*は知覚的な明るさを示す。

### FR-2: 操作と表示に追従する

#### 受け入れ条件

- 目盛りは色の点群と同じ回転・投影・サイズ変更に追従する。
- 軸ガイドを非表示にすると目盛りと数値も非表示になる。
- 数値は点群とスライスの上に背景付きで描画する。
- キャンバス境界内にラベルを収め、重なるラベルを間引く。縦軸と端点・中央の数値を優先する。
- 投影で軸が重なる角度では一部の数値が非表示になる。回転により確認できる。

## 6. 非機能要求

- ラベル数は最大15。ホバー探索対象に目盛りを追加しない。
- 描画中にReact stateを更新しない。

## 10. 未決事項

- なし。
