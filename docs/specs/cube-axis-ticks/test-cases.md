# Test Cases: 3D色空間の目盛り

## 対応要求

- FR-1: 正しい軸名と数値。
- FR-2: 操作追従と読みやすさ。

## 正常系

- TC-001: RGBでR/G/Bと0〜255の目盛りが描画される（FR-1）。
- TC-002: HSLでLの百分率とS·cos(H) / S·sin(H)の符号付き成分が描画される（FR-1）。
- TC-003: LabでL*とa*/b*の正負の値が描画される（FR-1）。
- TC-004: 軸ガイドをOFFにすると数値も消え、ONで再表示される（FR-2）。
- TC-005: 回転で目盛りの位置が変化し、サイズ変更でも点群と揃う（FR-2）。
- TC-006: 点群・画像マッピング・スライス表示中も目盛りが手前に描画される（FR-2）。

## エッジケース / 手動確認

- TC-101: 軸を正面から見たとき、重なる数値は間引かれる。回転すると再表示される（FR-2）。
- TC-102: 320 / 375 / 768 / 1024 / 1440幅でラベルがCanvasからはみ出さない（FR-2）。
- TC-103: サイズ最小・最大で点群に目盛りが追従する。数値の重なりがない（FR-2）。
