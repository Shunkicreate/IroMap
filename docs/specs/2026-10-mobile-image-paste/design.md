# Design: スマホの画像貼り付け

## 画像取り込み（FR-1/FR-2）

workbench 専用の clipboard-image.ts に paste イベントからの画像抽出を集約する。
items の file と files を順に調べ、MIME が空の場合だけ拡張子を補助情報に使う。
入力欄で preventDefault と stopPropagation を行い、HTML 挿入と二重適用を防ぐ。
入力文字は onInput で除去する。HTML や URL を解析・取得しない。

## 入力エリア（FR-2/FR-3）

画像選択ラベルと contenteditable の領域を、均等な 2 列の grid に配置する。
編集可能領域は textbox として名付け、空の疑似要素に「貼り付け」を表示する。
この領域が標準 paste イベントを受け取る。Async Clipboard API の読み取り経路は削除する。
フォーカス時だけ操作案内を表示し、aria-describedby で入力領域と関連付ける。
貼り付け実行時・フォーカス解除時に案内を閉じる。

見える見出しとアップロードの開閉は取り除き、入力とプレビューを常設する。
スクリーンリーダー向けの見出しは srOnly で残す。
表示設定と画像情報はプレビューの下に置き、ファイル名は画像情報内に残す。
テーマの surface と border を使い、ボタンの影・グラデーションを除く。

## 復帰と残余リスク（FR-4）

画像なしの場合はその場にファイル選択の案内を出し、成功時に解除する。
編集可能領域は OS のカーソルやキーボードを表示することがある。
ボタン風の外観でも OS のペーストメニューが使えるか、iPhone での再確認が必要。
依存方向と解析処理は変更しない。
