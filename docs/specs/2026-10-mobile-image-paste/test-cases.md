# Test Cases: スマホの画像貼り付け

## 自動テスト

- TC-001: files のみにある MIME 空・大文字 JPG 拡張子の JPEG を受け入れる（FR-1）。
- TC-002: 適用通知が一度だけ発生し、既存 items の JPEG 貼り付けも動作する（FR-1）。
- TC-003: 編集可能欄が存在し、HTML/URL を挿入・取得しない（FR-2）。
- TC-004: PNG の取得失敗後に別の画像形式を取得できる（FR-3）。
- TC-005: 既存の PNG/JPEG 貼り付け・画面全体ペーストが動作する（FR-1）。
- TC-006: 全画像形式の取得失敗を案内し、標準ペーストで復帰できる（FR-3）。
- TC-007: 320 / 375 / 768 / 1024 / 1440px の入力欄の収まりを確認（FR-2）。
- TC-008: 許可ダイアログ後を想定した read の NotAllowedError と getType の NotAllowedError を区別し、拒否と断定しない（FR-4）。
- TC-009: 未対応・画像なし・アクセス失敗・画像取得失敗に復帰案内があり、入力欄へ移動後の JPEG 貼り付けで案内が消える（FR-4）。
