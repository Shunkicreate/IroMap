# Feature Spec: 利用状況と操作導線の計測

## 目的

利用される機能、ボタンの入口と操作先、時系列の操作を GA4 で分析する。

## 機能要求

- FR-1: 主要ボタン、タブ、表示設定、スライダー、ファイル選択、開閉操作に固定の操作 ID と機能 ID を付けて計測する。
- FR-2: 画像入力、解析の開始・成功・失敗・中断、色・範囲選択、コピー・ペーストの成否をクリックと区別して計測する。
- FR-3: イベントにタブ内の journey ID、連番、時刻、経過時間、直前の操作、ページを付与する。リロード・同一タブのページ移動でも継続する。
- FR-4: 本番かつ測定 ID 設定済み、最新版の有効なアクセス解析同意がある場合のみ GA を読み込み・送信する。画像・ファイル名・色値・クリップボード・自由入力・URL のクエリを独自イベントに含めない。計測失敗は操作を妨げない。
- FR-5: CI で固定 ID の登録漏れと計測の回帰を検証する。GA 側の閲覧設定と詳細時系列の取得方法を文書化する。
- FR-6: 同意・拒否を同じ画面で選べる。既存のローカル保存と同様に localStorage に判断・文言バージョン・日時・有効期限を保存する。最新版との完全一致を必須とし、旧版・破損・未保存・365日経過は未同意とする。
- FR-7: 常設の Cookie 設定から撤回・再同意できる。撤回時は送信を即時無効化し、GA Cookie と journey を削除する。同意前の操作は保存・遡及送信しない。別タブでの撤回も反映する。
- FR-8: 目的、操作データの種類、GA の Cookie 識別情報、Google への送信、Cookie と同意の保存期間、撤回方法を説明する。同意を拒否しても画像分析を利用できる。
- FR-9: 同意後のページスクロールは25/50/75/90%の到達を画面ごとに一度計測し、移動座標や連続イベントは送らない。
- FR-10: 同意説明と詳細画面から、取得内容と送信の仕組みを確認できる公開リポジトリへ移動できる。
- FR-11: 同意済みのサービス改善目的・データの種類・Google Analyticsへの送信範囲内では、機能・操作・イベントの追加・変更に再同意を要求しない。イベント名の一覧は同意条件に含めない。送信先の追加、目的変更、取得するデータの種類や保存期間の拡大は、同意内容を更新して再同意を得た後に適用する。
- FR-12: CIは表示文言全体ではなく同意内容の範囲を検証する。イベントカタログの変更や意味を変えない文言修正で同意バージョンを変更する必要はない。同意範囲を変更した場合は、同じバージョンのまま上書きできない。

## 非機能要求と制約

- ホバー、描画フレーム、ポインター移動は送信しない。スライダーは操作確定時に送る。
- セッション保存不可時はメモリ上で継続する。journey は最後の計測から30分で切り替える。
- これはイベントログであり、画面録画ではない。GA の遮断やネットワーク切断に対する完全な収集は保証しない。
- API を直接呼ぶエージェントのアクセスはブラウザー計測の対象外。
- 本番の環境変数設定、GA 管理設定、BigQuery 接続はアカウント側の別作業として明記する。
