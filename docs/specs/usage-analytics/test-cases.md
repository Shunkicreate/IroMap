# Test Cases: 利用状況と操作導線の計測

## 正常系

- TC-001: 操作 ID が登録済みで、主要 UI に対応する（FR-1, FR-5）。
- TC-002: 入力・解析・選択・コピーの順序、時刻、直前の操作が取得できる（FR-2, FR-3）。
- TC-003: リロード・ページ移動で journey と連番が継続し、30分後に切り替わる（FR-3）。
- TC-004: 本番の初期化前の操作がキューされ、page_view が重複しない（FR-4）。
- TC-005: マウス・キーボードによるタブ選択、開閉、スライダー確定を計測する（FR-1）。

## 異常系

- TC-101: 未設定・開発環境で GA に送信しない（FR-4）。
- TC-102: 保存領域と送信が例外でも UI 操作が完了する（FR-4）。
- TC-103: ファイル名・自由入力・クエリ・色値を独自イベントに含めない（FR-4）。
- TC-104: 解析失敗・中断とコピー失敗を成功と区別する（FR-2）。
- TC-105: ホバー・連続描画をイベントにしない（FR-4）。
- TC-106: 旧版・未知の新版・期限切れ・破損データ・保存失敗ではタグを読み込まず、最新版の選択画面が出る（FR-6）。
- TC-107: 拒否しても画像分析を利用できる。最新版の選択と日時・期限を保存し、リロード後に復元する（FR-6, FR-8）。
- TC-108: 同じ画面・別タブからの撤回で送信無効化フラグが立ち、GA Cookieとjourneyが消え、表示設定は残る（FR-7）。
- TC-109: 再同意で新規journeyになり、以前の同意で開始した非同期処理の結果は送らない（FR-7）。
- TC-110: 同意前にはスクロールを保存せず、同意後に到達率のイベントを一度ずつ送る（FR-9）。
- TC-111: 320/375/768/1024/1440幅で横スクロールがなく、同意と拒否を選択できる。選択後にページ位置が変わらない（FR-8）。
- TC-112: 同意範囲のハッシュが現バージョンと一致し、公開済みバージョンを変更・削除できない（FR-6, FR-12）。
- TC-113: バージョン3のみ有効になり、同意期限とGA Cookieの期限が365日、自動延長なしである（FR-6）。
- TC-114: 同意画面と詳細説明から公開リポジトリへのリンクを参照できる（FR-10）。
- TC-115: 同意範囲内でイベントを追加・名称変更しても、保存済み同意が有効なまま送信できる（FR-11）。
- TC-116: イベント一覧や表示文言は同意範囲に含めず、目的・送信先・データの種類・保存期間の変更は範囲ハッシュを変える（FR-12）。
- TC-117: 詳細画面に、範囲内のイベント追加は再同意不要、範囲外の変更は適用前に再同意する方針が表示される（FR-11）。
