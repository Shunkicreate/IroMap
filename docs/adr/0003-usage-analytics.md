# ADR-0003: 許可リストによる GA4 操作計測

## Status

Accepted

## Context

機能利用・ボタンの導線・操作順を取得したい。テキストや DOM 全体の自動収集では、画像名や色、貼り付け内容の混入と表示文言変更による分析の分断が起きる。

## Decision

固定 ID の許可リストと意味のある処理完了イベントを GA4 に送り、タブ内 journey と連番で詳細な操作順を再構成する。

最新版の明示同意がある場合だけタグを読み込む。既存のローカル設定と同じlocalStorageに、
同意・拒否の選択、説明バージョン、日時、有効期限を保存する。旧版の同意は移行せず、再度確認する。
Google basic consent mode を使用し、広告関連は常に拒否する。
同意は目的・データの種類・送信先・保存期間などの範囲に対して得る。
その範囲内のイベント更新や意味を変えない文言修正は再同意を必要としない。
CIは公開済みの同意範囲のハッシュを書き換えられないように検査する。

## Consequences

- 表示言語に依存せず、操作意図と結果を区別できる。
- UI 追加時に ID の登録が必要になるため、CI で登録漏れを検査する。
- GA 標準集計では機能・操作・導線を閲覧し、詳細な時系列は BigQuery Export で扱う。
- 画面録画、ホバー座標、自由入力の自動収集は対象に含めない。
- 新しい送信先への提供、目的変更、取得する情報の種類・保持期間の拡大は範囲の更新と再同意を必要とする。撤回・期限切れの際は以後の送信を停止する。

## Alternatives Considered

- DOM テキストの自動収集: 入力内容の混入と文言変更の影響がある。
- クリックのみ: 非同期の失敗や Canvas の選択を正しく表現できない。
